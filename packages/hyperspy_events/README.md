# HyperSpy Events

Standalone event system extracted from HyperSpy. Provides `Event`, `Events`, and `EventSuppressor` classes for event-driven programming.

## Status

This package is currently staged in the [HyperSpy monorepo](https://github.com/hyperspy/hyperspy) and is not yet published independently.

## Editable install

```bash
venv/bin/pip install -e packages/hyperspy_events
```
